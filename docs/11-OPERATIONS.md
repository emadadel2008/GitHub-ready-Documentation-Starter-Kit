# 11 - Operations

## Daily Operations

- Check application health.
- Review critical alerts.
- Check failed jobs.
- Review capacity.
- Confirm backups.

## Operational Runbook

### Restart Application

1. Confirm incident.
2. Check logs.
3. Confirm restart is safe.
4. Restart using the approved method.
5. Validate health endpoint.
6. Record the action.
